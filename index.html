Drainage Canal Designer

Size an open drainage channel using Manning’s equation, with a built-in hydraulic drainage design workflow, optional preliminary Rational Method discharge estimate, reference checklist, and DPWH/NSCP guidance.

Code & safety note: Hydraulic sizing uses Manning open-channel flow and user-selected criteria, supported by a built-in drainage design workflow referencing DPWH DGCS Volume III (2015) and applicable project criteria. NSCP 2015 is relevant to structural design of reinforced-concrete components, but it does not by itself establish the canal’s hydraulic capacity. This tool does not perform a complete NSCP reinforced-concrete, soil-pressure, uplift, sliding, overturning, bearing, scour or geotechnical design. Confirm applicable DPWH DGCS/standard plans and site conditions before using results for construction.

03 / Hydraulic Drainage Design Manual & Reference Guide

Use this built-in guide as the design workflow alongside the applicable official manuals and project criteria. It is a concise implementation aid, not a reproduction of the DPWH manual.

Step A — Establish design discharge

If the design discharge is already provided by a hydrologic study, enter it in the Design Inputs panel. If it is not known, the Rational Method below can provide a preliminary estimate for suitable small catchments where accepted by the approving agency.

Rational Method: Q = 0.00278 × C × i × A, where A is in hectares and i is in mm/hr. Select rainfall intensity from the approved local IDF data for a justified return period and time of concentration. Do not treat default values as project criteria.

Preliminary estimated discharge: — m³/s

Step B — Hydraulic design workflow

  1. Confirm catchment boundary, land use, runoff assumptions, design storm/return period and time of concentration.
  2. Establish design discharge and any base flow, sediment, debris and future development allowance.
  3. Choose a practical channel type and lining; select Manning n based on actual material and condition.
  4. Set bed slope from survey and check downstream tailwater, backwater, transitions and outlet control.
  5. Size the section using Manning's equation; check capacity, velocity, Froude number, freeboard and permissible erosion/scour.
  6. Review inlet/outlet structures, bends, junctions, access, maintenance, sediment deposition and utility conflicts.
  7. Complete structural/geotechnical design separately for concrete thickness, reinforcement, soil pressure, uplift and foundation stability.

Reference documents and official sources

  • DPWH Design Guidelines, Criteria and Standards (DGCS), 2015 Edition — Volume III: Water Engineering Projects. This is the key Philippine DPWH reference to consult for applicable water engineering and drainage/flood-control design criteria. Access is controlled by DPWH; obtain the authorized current copy and verify applicable provisions. DPWH FOI reference page.
  • DPWH Department Order No. 103, s. 2021 — notes updated standard plans for various water engineering projects. Confirm current plans with the relevant DPWH office. Read the order (PDF).
  • NSCP 2015 — use applicable provisions for structural load and reinforced-concrete design where relevant; it is not the standalone source for hydrologic discharge, open-channel sizing or drainage freeboard criteria.
  • Project-specific references — approved local rainfall IDF curves, hydrologic study, geotechnical report, current DPWH standard plans/specifications, local government drainage criteria and written instructions from the approving authority.

Copyright note: the app summarizes the workflow and implements standard hydraulic equations; it does not embed or reproduce the proprietary DPWH DGCS text. Numeric defaults are user-editable assumptions, not official mandated values.
